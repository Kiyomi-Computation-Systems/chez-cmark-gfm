* What it is

A binding to the system ~libcmark-gfm~. It renders Markdown to HTML, XML,
CommonMark, and plain text; parses it to an immutable Scheme AST; and converts
that AST to SXML in HTML vocabulary, for the serializer of your choosing.

It is safe by default: raw HTML and unsafe link schemes are suppressed unless
you ask for them by name.

💡 Use it to build a static site like [[https://kiyomi-computation-systems.github.io/chez-cmark-gfm/][this one]].

It *compiles nothing*. There is no C shim and no generated configuration —
importing ~(cmark gfm)~ locates a libcmark-gfm on this machine and loads it —
so installing needs no compiler, no CMake, and no submodule checkout.

* Status

- Version *2.0*.
- Needs a cmark-gfm in ~0.29.0.gfm.x~; one outside that range is refused
  rather than used.
- Needs Chez Scheme *9.5.8* or later.
- Runs on *macOS* and *Linux*. *Windows is not supported* (ADR-0004).

* Install

** Prerequisites

Chez Scheme — the binary is ~chez~ on macOS and ~chezscheme~ on
Debian/Ubuntu — and cmark-gfm from your system's package manager:

#+begin_src sh
apt install chezscheme cmark-gfm     # Debian/Ubuntu
brew install chezscheme cmark-gfm    # macOS
#+end_src

RHEL, Fedora, and Alpine package no GFM library and need a one-time source
build. That recipe, the Debian package list, the version rules, and the order
the library is looked for in are all in [[file:docs/installing.md][docs/installing.md]].

** With Akku

Needs the [[https://gitlab.com/akkuscm/akku][akku]] command itself, which this repo does not install for you.
Run from a clone — ~akku install~ reads ~Akku.manifest~ from the current
directory; this package is not on Akku's own index, so that's the only
installation path proven here.

#+begin_src sh
akku install
. .akku/bin/activate
#+end_src

~(cmark gfm)~ then finds the system libcmark-gfm on its own, with nothing else
set and no compiler involved.

** From a clone

#+begin_src sh
git clone https://github.com/Kiyomi-Computation-Systems/chez-cmark-gfm
cd chez-cmark-gfm
make build                    # macOS
make build CHEZ=chezscheme    # Debian/Ubuntu
#+end_src

~make build~ is a preflight, not a build step: it prints the libcmark-gfm that
would be loaded, or exits non-zero naming the remedy. Running it is optional —
importing ~(cmark gfm)~ performs the same discovery either way.

** With ~make install~

Install into a prefix you own — no privileges, no compiler:

#+begin_src sh
make install PREFIX=$HOME/.local
export CHEZSCHEMELIBDIRS=$HOME/.local/lib/chez-cmark-gfm:
#+end_src

*The trailing colon is not a typo.* Assigning ~CHEZSCHEMELIBDIRS~ *replaces*
Chez's search path rather than extending it, so without the colon ~.~ is
dropped and relative imports stop resolving. ~make install~ prints that line
itself, and ~make check-install~ runs the line it printed.

Installing system-wide is the same command under ~sudo~: the default prefix
is root-owned on macOS and Debian alike, and its ~lib~ subdirectory may not
exist yet.

#+begin_src sh
sudo make install PREFIX=/usr/local
#+end_src

~make uninstall PREFIX=...~ removes the tree again, under whichever
privileges the install needed.

** Running your program

#+begin_src sh
CHEZSCHEMELIBDIRS=src: chez --program your-script.sps          # macOS
CHEZSCHEMELIBDIRS=src: chezscheme --program your-script.sps    # Debian/Ubuntu
#+end_src

from a clone. Under Akku, ~. .akku/bin/activate~ sets the variable for you;
after ~make install~, the export line above does.

* A taste

#+begin_src scheme
(import (rnrs) (cmark gfm))

(define doc "A ~~struck~~ word and a <b>raw</b> tag.\n")

;; Safe by default: raw HTML becomes a comment, with no flag to remember.
(markdown->html doc (default-cmark-options))
;; => "<p>A <del>struck</del> word and a <!-- raw HTML omitted -->raw<!-- raw HTML omitted --> tag.</p>\n"

;; The other behaviour exists, and has to be asked for by name.
(markdown->html doc (make-cmark-options 'unsafe-html? #t))
;; => "<p>A <del>struck</del> word and a <b>raw</b> tag.</p>\n"

;; SXML in HTML vocabulary, for the serializer of your choosing.
(markdown->sxml "A [link](/x) and a <b>raw</b> tag.\n")
;; => (*TOP* (p "A " (a (^ (href "/x")) "link") " and a "
;;               (*COMMENT* " raw HTML omitted ") "raw"
;;               (*COMMENT* " raw HTML omitted ") " tag."))
#+end_src

Adapted from [[file:examples/01-rendering.sps][examples/01-rendering.sps]] and [[file:examples/04-sxml.sps][examples/04-sxml.sps]].
~make examples~ diffs those two files against pinned output, so they cannot
go stale silently — this adapted copy is not re-checked against them, so
verify it by eye if either file changes.

* Contributing

Issues and pull requests are welcome — see [[file:CONTRIBUTING.md][CONTRIBUTING.md]] for the full guide.
~make help~ lists every target and [[file:docs/building.md][docs/building.md]] says what each one checks; a
pull request is expected to keep ~make test~, ~make examples~, and the
~check-*~ targets green. A change in behaviour needs a test that fails
against the old behaviour.

Please report suspected vulnerabilities privately rather than in a public
issue — see [[file:SECURITY.md][SECURITY.md]].
